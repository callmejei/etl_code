## 🎯 How to Download

### Method 1: Download Individual Files (Recommended)
1. Navigate to the [docs folder](./docs/)
2. Click on the file you want (e.g., `.html`, `.txt`, or `.md`)
3. Click the "Raw" button or "Download" button
4. The file will download to your computer

### Method 2: Clone the Repository
```bash
git clone https://github.com/callmejei/etl_code.git
cd etl_code/docs
```

### Method 3: Download All Files as ZIP
1. Click the green "Code" button on the main repository page
2. Select "Download ZIP"
3. Extract the ZIP file
4. Navigate to the `docs` folder

## 💾 Converting to Other Formats

### Convert to PDF

**Option A: From HTML File (Easiest)**
1. Open `Enterprise_BigData_Platform_Governance_Standards.html` in any web browser
2. Press Ctrl+P (Windows) or Cmd+P (Mac)
3. Select "Save as PDF" as the destination
4. Click "Save"

**Option B: Using Microsoft Word**
1. Open the document in Word (see above)
2. File → Save As → PDF

**Option C: Using Google Docs**
1. Open in Google Docs (see above)
2. File → Download → PDF Document (.pdf)

**Option D: Online Converter**
- Go to [Markdown to PDF](https://www.markdowntopdf.com/)
- Upload the `.md` file
- Download the generated PDF
