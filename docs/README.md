## Converting to Other Formats

### Convert to Microsoft Word (.docx)
If you need a Word document, you can:

**Method 1: Use Pandoc (if installed)**
```bash
pandoc Enterprise_BigData_Platform_Governance_Standards.md -o governance.docx
```

**Method 2: Use Microsoft Word**
1. Open Microsoft Word
2. Go to File → Open
3. Select the `.md` file
4. Save As → Word Document (.docx)

**Method 3: Use Google Docs**
1. Open Google Docs
2. File → Open → Upload the `.md` or `.html` file
3. File → Download → Microsoft Word (.docx)

### Convert to PDF

**Method 1: From HTML file**
1. Open the `.html` file in a web browser
2. Print → Save as PDF

**Method 2: Use Pandoc (if installed)**
```bash
pandoc Enterprise_BigData_Platform_Governance_Standards.md -o governance.pdf
```

**Method 3: Use Microsoft Word**
1. Open the document in Word (see above)
2. File → Save As → PDF

**Method 4: Use Google Docs**
1. Open in Google Docs (see above)
2. File → Download → PDF Document (.pdf)
